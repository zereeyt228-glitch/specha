04 / НА СЛУЧАЙ «А КАК?»

Пара слов
перед стартом.

Как начать общаться?＋

Скачай Windows-приложение и запусти .exe. Владелец компании запускает сервер на своём компьютере и делится кодом подключения. Подключись по коду, создай аккаунт и присоединяйся к сообществу.

Нужно ли устанавливать приложение?＋

Нет, версия 0.7.1 — portable: она запускается из одного файла. Данные приложения сохраняются в папке %APPDATA%/durichat/data. Внутри эта сборка называется DuriChat.

Почему Windows показывает предупреждение?＋

У текущей сборки нет сертификата подписи издателя. Windows может показать предупреждение при запуске. Используй файл из этого блока загрузки и запускай его, только если доверяешь проекту.

А что с macOS и телефоном?＋

Сейчас здесь доступна только сборка для Windows. Установщиков для macOS, Linux, iOS и Android в проекте пока нет.

Где хранятся сообщения?＋

Сообщения и файлы сообщества хранятся на компьютере владельца сервера. Для связи сервер должен работать и быть доступен участникам. Владелец управляет приглашениями, каналами и участниками.
